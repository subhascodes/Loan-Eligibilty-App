About the Project

Loan Eligibility Prediction App

This project was built to make loan screening faster and easier to understand. It uses a trained machine learning model to predict approval outcomes from applicant details, and it includes a visualization page for exploring the dataset behind those predictions.

What It Does

Built for practical eligibility checks

Users enter applicant details, the app sends those values through the prediction pipeline, and the result is shown on a clear approval or rejection screen. The goal is to provide a simple, explainable workflow rather than a black-box experience.
